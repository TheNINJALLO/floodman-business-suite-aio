Floodman Operations App

Created by Josh Aldrich

Install one adaptive Floodman app. Computers open a true desktop shell; phones and tablets open the dedicated field shell. You can switch workspaces at any time, and live customer and billing data remains network-only.

PWA readiness

Install on iPhone or iPad

  1. Open Floodman in Safari or another current iOS browser.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Confirm Floodman, then tap Add.

HTTPS is the last switch

The PWA files are installed and ready, but browsers will not register the service worker or promote installation from a public plain-HTTP IP address. Point your Floodman subdomain to this service and enable HTTPS. No new application build is required afterward.

Offline behavior

The app shell, branding, icons, install page, and offline recovery page are cached. Customer records, signatures, invoices, payments, messages, and APIs are deliberately never cached, preventing private business data from lingering in the browser cache.
