# Floodman Operations for iPhone and iPad

Release candidate: `0.1.0-alpha02` (marketing version `0.1.0`, build `2`).

Native SwiftUI shell using the encrypted Floodman Mobile API. The complete pinned RoomFlow field-estimating engine is bundled locally and synchronized through the same customer, property, job, layout, and estimate records as Android and the private PWA.

The first GitHub Xcode 26 compiler pass is addressed in this build: the local asset server now uses valid optional binding, the device name is read through the main actor, and the `Any`-value text interpolation warnings are removed.
