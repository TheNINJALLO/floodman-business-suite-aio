===================
443 -> http://127.0.0.1:9010

Public gateway routing
======================
/mobile-api/* -> Floodman Office mobile API on 127.0.0.1:8700
/customer/*   -> customer estimates, invoices, documents, and payments on 127.0.0.1:8700
other paths   -> customer signing service on 127.0.0.1:9001

Production note
===============
The Funnel route was selected for controlled testing. Move the public mobile API and customer endpoints to a conventional HTTPS gateway and a Floodman-owned domain before broad production distribution.
